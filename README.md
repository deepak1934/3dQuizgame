# 🧠 3D Quiz Game with Three.js

This project is a 3D **Quiz Game** built using **Three.js**, where players interact with quiz elements inside a 3D environment. It combines educational gameplay with immersive 3D visuals.

## 🎮 Features

- 📋 Multiple-choice quiz questions in a 3D scene
- 🎯 Clickable answers with immediate feedback
- 🖱️ Mouse interaction using raycasting
- 🧠 Modular design for adding new questions
- 💡 Real-time score tracking (if implemented)
- 🚀 Animated feedback and transitions (optional)

## 🛠️ Tech Stack

- **Three.js** – 3D rendering
- **JavaScript** – Game logic
- **HTML/CSS** – Basic layout and styling
